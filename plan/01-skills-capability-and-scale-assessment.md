### Key Structural Bottlenecks Observed Across the Current Skill Suite

1. ~~**Duplicated Governance Logic:** The Pure Open-Source Systems Mandate, `Scope & Licensing Note` boilerplate, `[NEW]`/`[UPDATED]` badge rules, and `articles/CHANGELOG.md` update rules are repeated across 4 separate `SKILL.md` files.~~ **Resolved (Option 4):** Declarative invariants (Pure Open-Source Systems Mandate & `Scope & Licensing Note`, `kebab-case.md` layout, immutable `**Date:**` / `**Last Updated:**` / `## Changelog` ordering, and Hybrid Window `[NEW]` / `[UPDATED]` formulas) are centralized in always-on [`.agent/rules/AGENTS.md`](../.agent/rules/AGENTS.md), procedural index/badge/changelog mutation is consolidated into [`organize_readme`](../.agent/skills/organize_readme/SKILL.md), and legacy `view_file` tool coupling was removed from [`simplify_article`](../.agent/skills/simplify_article/SKILL.md).
2. ~~**Multi-Writer Contention Risk:** All 4 content skills still trigger singleton file mutations ([`README.md`](../README.md), [`articles/README.md`](../articles/README.md), [`articles/CHANGELOG.md`](../articles/CHANGELOG.md)) at runtime via `organize_readme` until converted to scoped subagents + the single-writer `index-reconciler` agent.~~ **Resolved (Option A4):** Content skills ([`create_article`](../.agent/skills/create_article/SKILL.md), [`update_article`](../.agent/skills/update_article/SKILL.md), [`simplify_article`](../.agent/skills/simplify_article/SKILL.md), and `review_article`'s `Article Remediator`) now strictly restrict edits to target article files and emit validated [`INDEX_HANDOFF_SCHEMA`](../.agent/skills/review_article/scripts/schemas.py) payloads to the deterministic single-writer engine [`reconcile_indexes.py`](../.agent/skills/organize_readme/scripts/reconcile_indexes.py), raising `organize_readme` to `9.5 / 10` and eliminating concurrent badge/count race conditions.
3. ~~**Unstructured Inter-Agent Outputs:** `review_article` currently relies on ad-hoc subagent prompt generation and free-text score extraction rather than schema-validated JSON contracts.~~ **Resolved (Option B4):** [`run_review_workflow.py`](../.agent/skills/review_article/scripts/run_review_workflow.py) orchestrates three persistent read-only reviewer handles across Stage 1 (`BEFORE_SCORECARD_SCHEMA`) and Stage 4 (`AFTER_SCORECARD_SCHEMA`) via `run_workflow` `parallel()`, enforces anti-inflation clamping and deterministic Python arithmetic/Check 7 report rendering in [`schemas.py`](../.agent/skills/review_article/scripts/schemas.py), raising `review_article` to `9.7 / 10`.
4. ~~**Missing Pre-Push Gate:** `commit_and_push` can push a broken repository state if executed directly without first running `bash verify_links.sh`.~~ **Resolved (Option 4 + Check 8):** [`commit_and_push`](../.agent/skills/commit_and_push/SKILL.md) now gates `jj describe`, `jj bookmark set`, and `jj git push --bookmark` behind [`prepare_commit.sh`](../.agent/skills/commit_and_push/scripts/prepare_commit.sh) (`verify_links.sh` Checks 1–8 == exit `0`), raising its composite maturity score from `5.0` to `7.8` (`9.25` ex-orchestration).
5. ~~**IDE / Parser Diagnostics on Skill Python Files (Strategy S4):** Top-level `await`, unbound `run_workflow` globals, and dynamic `sys.path` imports caused Pylance/Pyright/`py_compile` failures.~~ **Resolved (Strategy S4 + `uv`/`pip`):** Refactored [`run_review_workflow.py`](../.agent/skills/review_article/scripts/run_review_workflow.py) into a standard-Python module (`async def run_pipeline(runtime_env)` invoked via `runpy.run_path` + offline `--self-test`), added [`pyrightconfig.json`](../pyrightconfig.json), [`pyproject.toml`](../pyproject.toml), [`requirements.txt`](../requirements.txt), Python [`.gitignore`](../.gitignore) rules, [`run_python.sh`](../.agent/skills/organize_readme/scripts/run_python.sh) + `ensure_dependencies()` (`uv` primary / `pip` fallback), and enforced Checks 1–8 in [`verify_links.sh`](../verify_links.sh).
