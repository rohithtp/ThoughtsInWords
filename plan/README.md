## Executive Architectural Summary

1. **Do not convert skills 1-to-1 into unconstrained write-enabled agents.** Converting all 6 skills into independent agents that mutate singleton indexes ([`README.md`](../README.md), [`articles/README.md`](../articles/README.md), [`articles/CHANGELOG.md`](../articles/CHANGELOG.md), [`reviews/README.md`](../reviews/README.md)) introduces write contention and badge-rotation drift.
2. **Adopt a Pure Hybrid Control Plane (Thin Routing Skills + Scoped `run_workflow` Engines + Pre/Post Deterministic Gates + Single-Writer Reconciler):**
   * **High ROI (`9.9 / 10` — Options B4 + H3):** [`review_article`](../.agent/skills/review_article/SKILL.md) runs via [`run_review_workflow.py`](../.agent/skills/review_article/scripts/run_review_workflow.py) with 3 stateful read-only reviewer handles (configurable `reviewer_type` / model tiering) across single or batch `article_paths`, Stage 3 `verify_article_mutation()` gating, deterministic Python math/Check 7 rendering, and anti-inflation clamping in [`schemas.py`](../.agent/skills/review_article/scripts/schemas.py).
   * **Symmetric Hybrid Content Orchestration (`9.6 / 10` — Option H3):** [`create_article`](../.agent/skills/create_article/SKILL.md), [`update_article`](../.agent/skills/update_article/SKILL.md), and [`simplify_article`](../.agent/skills/simplify_article/SKILL.md) route single or parallel batch (`workspace: "share"`) workloads through [`run_content_workflow.py`](../.agent/skills/create_article/scripts/run_content_workflow.py), enforcing `CONTENT_MUTATION_RESULT_SCHEMA` and `verify_article_mutation()` (immutable `**Date:**`, Invariant 3 ordering, and 100% link retention) before index reconciliation.
   * **Concurrency & Reciprocal Trail Safety (`9.8 / 10` — Options A4 + H3):** [`organize_readme`](../.agent/skills/organize_readme/SKILL.md) executes via the deterministic single-writer [`reconcile_indexes.py`](../.agent/skills/organize_readme/scripts/reconcile_indexes.py), consuming `INDEX_HANDOFF_SCHEMA` payloads, auto-expanding `reciprocal_articles_touched` via `expand_reciprocal_handoffs()`, and running [`verify_links.sh`](../verify_links.sh).
   * **Keep as Guarded Skill (`2.0 / 10` ROI — Option 4):** Keep [`commit_and_push`](../.agent/skills/commit_and_push/SKILL.md) as a two-phase procedural skill gated by [`prepare_commit.sh`](../.agent/skills/commit_and_push/scripts/prepare_commit.sh) (`bash verify_links.sh` Checks 1–8 before `jj describe`, `jj bookmark set`, and `jj git push --bookmark`).
   * **IDE & `uv`/`pip` Dependency Integrity (Strategy S4 + Check 8):** [`run_review_workflow.py`](../.agent/skills/review_article/scripts/run_review_workflow.py) and [`run_content_workflow.py`](../.agent/skills/create_article/scripts/run_content_workflow.py) run as standard-Python modules (via `runpy.run_path` inside `run_workflow` + offline `--self-test`), paired with [`pyproject.toml`](../pyproject.toml), [`requirements.txt`](../requirements.txt), [`pyrightconfig.json`](../pyrightconfig.json), [`.gitignore`](../.gitignore) Python ignores, [`run_python.sh`](../.agent/skills/organize_readme/scripts/run_python.sh) (`uv` primary / `pip` fallback), and `verify_links.sh` Check 8 across all 4 Python engines (`schemas.py`, `run_review_workflow.py`, `run_content_workflow.py`, `reconcile_indexes.py`).
